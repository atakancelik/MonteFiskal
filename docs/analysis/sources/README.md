# Sources

All sources used by the analysis package. Access date for every row is **2026-11-13** unless stated otherwise.

## Copy policy

No source document is stored in this repository. The specifications, the law text and the schema files carry no licence statement, so their redistribution rights are unclear. Every row is therefore a link plus a SHA-256 digest of the bytes that were read, so that a later reader can tell whether the document they download is the one this analysis was built on. `message-catalog.json` is a derived description of the schema, not a copy of it.

The same applies to third-party code: the reference implementations below were read for behaviour only. No code, no certificate and no key from them is present in this repository.

## Identifiers

Other documents cite sources by the ID in the first column, followed by a section, article or table number, for example `[D-01 §3.7.7]`.
